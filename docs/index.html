02 / EVIDENCE MODEL

Facts over folklore.

Every statement carries a clear level of confidence.

Engineering, not guesswork.

This project distinguishes what the source code proves from what an engineer can reasonably infer - and from questions that still need experiments. Benchmarks are workload-specific; implementation details are tied to upstream source.

VERIFIED

Directly supported by inspected source code or tests.

ANALYSIS

An interpretation of observed implementation and likely consequences.

HYPOTHESIS

03 / RESEARCH PRINCIPLES

Follow the real call path.

A / SOURCE FIRST

Implementation before interpretation.

B / TRACE END TO END

Connect the layers.

C / MEASURE

No performance theatre.

Separate asymptotic reasoning from observed benchmark results.

D / STAY HONEST

Expose what's unknown.

Keep open questions visible and update conclusions when the code changes.
